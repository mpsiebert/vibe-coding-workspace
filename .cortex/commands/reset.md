Reset the Vibe Coding booth workspace for the next attendee.

Run `./reset.sh` from the workspace root. This should stop any running Streamlit process, clear `app.py`, remove stale Python cache, and leave the workspace ready for a fresh `/vibe-coding` run.

After the reset completes, tell the facilitator to hand the keyboard to the next attendee and run `/vibe-coding`.
